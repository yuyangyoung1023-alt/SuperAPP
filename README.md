# iCAR Claw APP V2.0 可交互 Demo

普通交互可直接打开 `index.html` 使用；语音体验需要通过 GitHub Pages 或本地网页服务访问。首页按 16:9 车机屏幕设计，已适配 1280×720 与 1920×1080；推荐使用最新版 Chrome 或 Edge 全屏演示。

当前工程已经升级为可安装的 PWA Web App，包含应用清单、离线缓存、横屏启动配置与 GitHub Pages 自动部署流程。发布后可以在浏览器中选择“安装应用”或“添加到主屏幕”，以独立窗口运行。

## 建议演示路径

1. 首页左侧分别展示「系统预置」与「我的场景」中已经启动的场景；点击“关闭”后，该场景立即从首页移除，但不会删除配置。
2. 点击系统场景卡片会打开简洁的图文详情，清楚展示触发条件、自动任务和执行记录。系统规则只读，只支持开启或关闭。
3. 点击我的场景卡片会直接请求麦克风。说出修改要求后，卡片会自动完成语义理解、规则对照、权限与冲突检查、配置更新和账号同步，不使用表单，也不需要逐步确认。
4. 首页右侧通过六个 TAB 查看车辆控制、出行助手、车辆知识问答、生活服务、媒资娱乐和 iCAR 趣玩；上方为自适应分类演示，下方为对应技能卡片。
5. 每张技能卡片只展示用户能理解的能力价值。点击卡片可查看完整介绍，点击“快速了解”可观看对应的动态图文演示。
6. 点击首页顶部语音入口或技能详情中的“语音体验”后，页面会申请电脑麦克风权限。允许后只需说出一次完整需求，不需要继续点击任何按钮。
7. 语音识别结束后，屏幕上方居中的交互卡片会动态展示 Master Agent 的任务拆解，并按“等待 → 执行中 → 完成”自动逐项向下推进，最后通过卡片和语音反馈结果。
8. 「测测」采用星座能量主题，「神算子」采用今日签主题，「旅途影像」采用照片故事主题，同时保留统一的语音识别和自动任务编排体验。
9. 「视野受阻主动恢复、身份识别与偏好恢复、导航前全景预检、沿途景点介绍、停车推荐、车辆状态异常守护、情景化迎宾、记忆迎宾」等无需用户先开口的能力统一归入系统预置；「路途待办提醒」作为可语音创建的我的场景模板。
10. 在推荐区进入「Claw 发现了你的习惯」，查看依据和预览，然后新建或合并到已有场景。
11. 使用「＋创建场景」，体验自然语言生成、「调整一下」和真实保存。
12. 在首页直接说“导航回家，再放点轻松的歌”，体验多任务理解和自动编排；第三方服务完成授权后会恢复原任务。
13. 在「我的记忆」体验六类筛选、单条编辑删除、批量管理与清空。
14. 在「账号、隐私与权限」关闭 Memory、座舱环境感知或车外环境感知，再返回首页及主动服务查看实时降级。
15. 退出账号，查看账号资产隐藏；重新登录同一账号后恢复原状态。
16. 体验 Face ID、声纹录入、语音开关联动，以及角色引擎的音色、性格、表达方式、主动程度和称呼实时预览。

## 状态说明

Demo 使用浏览器本地存储保留状态，刷新后仍会恢复。若需从初始状态重新演示，请清除此页面的站点数据或在浏览器控制台执行 `localStorage.removeItem('icarClawV2')` 后刷新。

本 Demo 为单文件前端原型，第三方授权、身份录入、车辆能力与账号同步均为可交互模拟，不会连接真实服务或采集真实数据。

## 麦克风运行要求

浏览器只允许安全页面使用麦克风。请使用最新版 Chrome 或 Edge，并通过以下任一方式打开：

- 上传到 GitHub Pages 后通过 `https://` 地址访问；
- 在文件目录启动本地网页服务，通过 `http://localhost` 访问。

不建议直接双击 `index.html` 以 `file://` 方式打开，因为部分浏览器不会向本地文件开放麦克风和语音识别能力。首次点击首页语音入口、我的场景或“语音体验”时，请允许浏览器使用麦克风。

## GitHub Pages 发布

工程已包含 `.github/workflows/pages.yml`。上传到 GitHub 仓库并推送到 `main` 分支后：

1. 进入仓库的 Settings → Pages；
2. 将 Source 设为 GitHub Actions；
3. 等待 `Deploy iCAR Claw Demo` 工作流完成；
4. 使用 GitHub 提供的 `https://<用户名>.github.io/<仓库名>/` 地址访问。

Pages 的 HTTPS 环境可以正常发起麦克风权限请求。语音识别能力仍取决于访问者使用的浏览器，推荐最新版 Chrome 或 Edge。

页面统一使用用户能理解的能力描述，不展示研发阶段、落地范围或内部限制标签；缺少权限时只说明需要用户开启的能力。
