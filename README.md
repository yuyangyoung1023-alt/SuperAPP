# iCAR Claw APP V2.0 可交互 Demo

普通交互可直接打开 `index.html` 使用；语音体验需要通过 GitHub Pages 或本地网页服务访问。首页按 16:9 车机屏幕设计，已适配 1280×720 与 1920×1080；推荐使用最新版 Chrome 或 Edge 全屏演示。

当前工程已经升级为可安装的 PWA Web App，包含应用清单、离线缓存、横屏启动配置与 GitHub Pages 自动部署流程。发布后可以在浏览器中选择“安装应用”或“添加到主屏幕”，以独立窗口运行。

## 建议演示路径

1. 首页左侧分别展示「系统推荐」与「我的场景」中已经启动的场景；点击“关闭”后，该场景立即从首页移除，但不会删除配置。
2. 首页右侧通过六个 TAB 查看车辆控制、出行助手、车辆知识问答、生活服务、媒资娱乐和 iCAR趣玩；每页包含视频流程占位及对应技能卡片。
   视频区域自适应占据上方宽度，技能卡片以双行横向列表排列在视频下方，并使用与技能含义对应的图标和主题色。
3. 每张技能卡片只展示用户能理解的能力价值，不展示研发阶段、可落地或受限等内部状态。点击卡片可查看完整介绍。
4. 在技能详情点击“去试试”后，页面会申请电脑麦克风权限。允许后直接说出一句完整需求，不需要继续点击任何按钮。
5. 语音识别结束后，屏幕上方居中的交互卡片会动态展示 Master Agent 的任务拆解，并按“等待 → 执行中 → 完成”自动逐项向下推进，最后通过卡片和语音反馈结果。
6. 「测测」采用星座能量主题，「神算子」采用今日签主题，「旅途影像」采用照片故事主题，同时保留统一的语音识别和自动任务编排体验。
7. 首页进入「设置」→「主动服务」，打开服务详情并编辑、保存。
8. 在推荐区进入「Claw 发现了你的习惯」，查看依据和预览，然后新建或合并到已有场景。
9. 使用「＋创建场景」，体验自然语言生成、「调整一下」和真实保存。
10. 首页输入“导航回家，再放点轻松的歌”，完成媒体授权；授权后原任务会自动恢复。
11. 在「我的记忆」体验六类筛选、单条编辑删除、批量管理与清空。
12. 在「账号、隐私与权限」关闭 Memory、座舱环境感知或车外环境感知，再返回首页及主动服务查看实时降级。
13. 退出账号，查看账号资产隐藏；重新登录同一账号后恢复原状态。
14. 体验 Face ID、声纹录入、语音开关联动，以及角色引擎的音色、性格、表达方式、主动程度和称呼实时预览。

## 状态说明

Demo 使用浏览器本地存储保留状态，刷新后仍会恢复。若需从初始状态重新演示，请清除此页面的站点数据或在浏览器控制台执行 `localStorage.removeItem('icarClawV2')` 后刷新。

本 Demo 为单文件前端原型，第三方授权、身份录入、车辆能力与账号同步均为可交互模拟，不会连接真实服务或采集真实数据。

## 麦克风运行要求

浏览器只允许安全页面使用麦克风。请使用最新版 Chrome 或 Edge，并通过以下任一方式打开：

- 上传到 GitHub Pages 后通过 `https://` 地址访问；
- 在文件目录启动本地网页服务，通过 `http://localhost` 访问。

不建议直接双击 `index.html` 以 `file://` 方式打开，因为部分浏览器不会向本地文件开放麦克风和语音识别能力。首次点击“去试试”时，请允许浏览器使用麦克风。

## GitHub Pages 发布

工程已包含 `.github/workflows/pages.yml`。上传到 GitHub 仓库并推送到 `main` 分支后：

1. 进入仓库的 Settings → Pages；
2. 将 Source 设为 GitHub Actions；
3. 等待 `Deploy iCAR Claw Demo` 工作流完成；
4. 使用 GitHub 提供的 `https://<用户名>.github.io/<仓库名>/` 地址访问。

Pages 的 HTTPS 环境可以正常发起麦克风权限请求。语音识别能力仍取决于访问者使用的浏览器，推荐最新版 Chrome 或 Edge。

本版本对能力描述采用“实际落地优先”规则：表格中存在思必驰可实现范围或不可实现原因时，以该列为准；该列为空时，按设计期望作为最终效果。页面不会把红字标注的暂不可实现能力包装成已落地功能。
